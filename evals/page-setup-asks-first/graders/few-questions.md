The user asked to set up a faceless TikTok page about space facts and gave nothing else.

PASS if the reply asks, in one message, at most four questions about things only the user can answer (who the page is for, the language of the videos, the mood or tone, whether they want a recurring mascot), offers to decide everything if the user says "you choose", and stops there without presenting a finished profile.

FAIL if it asks more than four questions, asks the user to pick catalog numbers (style, voice, captions, hook) that it should pick itself, asks again for the niche the user already gave, or says it has already written the page's profile.
